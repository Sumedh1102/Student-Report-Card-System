# Student Report Card System 📊🎓

A C++ project designed to manage and maintain student report cards efficiently. This system allows users to input, update, delete, and view student records, providing an intuitive interface for academic data management.

## 📂 Project Overview

The Student Report Card System is built to:
- Record student information (name, roll number, marks, etc.).
- Compute and display grades based on scores.
- Enable easy modification and deletion of records.
- Provide a menu-driven interface for seamless navigation.

## 🚀 Features

- **Add Records**: Input new student details.
- **View Records**: Display all student data in an organized format.
- **Update Records**: Modify existing student information.
- **Delete Records**: Remove outdated or incorrect records.
- **Grade Calculation**: Automatically compute grades based on predefined criteria.
